# Risk Assessment & Gap Analysis (AWS 3-Tier Architecture)

This document outlines the qualitative risk assessment and security gap analysis performed for the reference 3-tier web application architecture on AWS, based on **ISO/IEC 27001:2022** controls and **CIS AWS Foundations Benchmark** guidelines.

### Risk Scoring Methodology
* **Formula:** $\text{Risk Level} = \text{Likelihood (1-5)} \times \text{Impact (1-5)}$
* **Scale:** 
  * 1–6 = Low
  * 8–14 = Medium
  * 15–25 = High / Critical
